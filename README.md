# WB Анализатор видео - Веб-интерфейс

Веб-интерфейс для модели анализа товаров на видео с использованием технологий самоконтролируемого обучения (SSL). Приложение позволяет определить, присутствует ли заданный товар на видео, и предоставляет подробный анализ сходства.

## Описание проекта

Этот веб-интерфейс предназначен для работы с моделью искусственного интеллекта, которая анализирует, присутствует ли загруженный по фото товар на видео. Проект разработан для маркетплейса Wildberries, поэтому интерфейс выполнен в стиле их официального сайта.

### Основные возможности

- Загрузка видео для анализа в форматах MP4, AVI, MOV, WEBM
- Загрузка нескольких изображений товаров для поиска на видео (поддерживаются JPG, JPEG, PNG, WEBP)
- Настройка параметров анализа:
  - Порог обнаружения (от 0.5 до 1.0)
  - Частота выборки кадров (от 1 до 30)
- Визуализация результатов анализа с интерактивными графиками и статистикой
- Отображение ключевых метрик:
  - Максимальное сходство
  - Среднее сходство
  - Общее время появления товара на видео
- Просмотр детальной информации по каждому товару
- Возможность экспорта результатов в PDF
- Сохранение истории анализов для дальнейшего использования

## 🌟 Особенности модели SSL

- **Обучение без разметки**: модель использует неразмеченные данные для обучения
- **Поиск по образцу**: находит любой объект на видео, имея только его изображение
- **Высокая точность**: модель достигает значения loss до 0.22 при обучении
- **Оптимизация для GPU**: максимальная производительность на NVIDIA CUDA
- **Визуализация результатов**: наглядное представление найденных объектов

## 🧠 Принцип работы модели

### Самоконтролируемое обучение (SSL)

ObjectFinder использует контрастивное самоконтролируемое обучение, которое позволяет модели учиться на неразмеченных данных. Основная идея:

1. **Создание различных представлений**: из каждого изображения создаются два разных вида с помощью случайных преобразований (поворот, изменение яркости, контраста и т.д.)
2. **Контрастивное обучение**: модель учится приближать представления одного и того же изображения и отдалять представления разных изображений в скрытом пространстве
3. **Формирование представлений**: в процессе обучения модель создает высокоуровневые представления объектов, выделяя их ключевые характеристики

### Архитектура модели

- **Базовая сеть**: ResNet50, извлекающая признаки из изображений
- **Проекционная голова**: преобразует 2048-мерные признаки в 128-мерное представление
- **Функция потерь**: NT-Xent (Normalized Temperature-scaled Cross Entropy Loss)

### Процесс обнаружения объектов

1. Модель извлекает признаки из целевого изображения объекта
2. Для каждого кадра видео извлекаются аналогичные признаки
3. Вычисляется косинусное сходство между целевым объектом и кадром
4. Если сходство выше порогового значения, объект считается найденным

## Использование приложения

### 1. Анализ видео

1. Перейдите на страницу "Анализ видео"
2. Загрузите видеофайл, нажав на кнопку "Загрузить видео"
3. Загрузите изображения товаров, которые вы хотите найти на видео
4. Настройте параметры анализа:
   - **Порог обнаружения**: Чем выше значение, тем точнее обнаружение, но больше шанс пропустить товар
   - **Частота выборки кадров**: Определяет, через сколько кадров будет выполняться анализ (влияет на скорость и детализацию)
5. Нажмите кнопку "Начать анализ"
6. Дождитесь завершения анализа (процесс может занять несколько минут в зависимости от длительности видео)

### 2. Просмотр результатов

После завершения анализа вы будете перенаправлены на страницу результатов, где можно:
- Изучить график сходства для каждого товара
- Просмотреть ключевые метрики (максимальное и среднее сходство)
- Открыть видео с найденным товаром
- Экспортировать результаты в PDF формат

### 3. Экспорт отчета

Чтобы экспортировать результаты анализа в PDF:
1. На странице результатов нажмите кнопку "Скачать отчет"
2. Дождитесь генерации PDF-файла
3. Файл автоматически загрузится в браузере

## API документация

### Основные эндпоинты

- **POST /api/analyze**: Загрузка видео и изображений для анализа
  - Параметры:
    - `video`: Файл видео
    - `product_image_{index}_{image_index}`: Файлы изображений товаров
    - `threshold`: Порог обнаружения (float, default: 0.85)
    - `sample_rate`: Частота выборки кадров (int, default: 10)
  - Ответ: Объект с результатами анализа

- **GET /api/results/{result_id}**: Получение результатов анализа по ID
  - Параметры пути:
    - `result_id`: ID анализа или "latest" для последнего результата
  - Ответ: Объект с результатами анализа

- **GET /api/results**: Получение списка всех анализов
  - Параметры запроса:
    - `page`: Номер страницы (int, default: 1)
    - `limit`: Количество результатов на странице (int, default: 10)
  - Ответ: Массив объектов с результатами анализа

- **GET /static/{filename}**: Получение статических файлов (изображения, видео)
  - Параметры пути:
    - `filename`: Путь к файлу
  - Ответ: Файл

- **GET /video/{video_id}**: Получение видео по ID
  - Параметры пути:
    - `video_id`: ID видео
  - Ответ: Видеофайл

## Возможные проблемы и их решение

### Ошибка 405 Method Not Allowed при анализе видео

**Причина**: Конфликт маршрутов на сервере или проблема с CORS.

**Решение**:
1. Убедитесь, что сервер запущен из корневой директории проекта
2. Перезапустите сервер Flask
3. Проверьте, что маршрут `/api/analyze` не конфликтует с другими маршрутами

### Ошибка при загрузке модели

**Причина**: Отсутствие файла модели или несовместимая версия PyTorch.

**Решение**:
1. Убедитесь, что файл `models/ssl_model_epoch_80.pth` существует
2. Проверьте, что модель скачана по [ссылке](https://disk.yandex.ru/d/AQuNJMU5D-q9FQ) с паролем 1510
3. Переустановите PyTorch с правильной версией для вашей системы

### Ошибка при установке PyTorch

**Причина**: Несовместимость версий или проблемы с CUDA.

**Решение**: 
1. Посетите [официальный сайт PyTorch](https://pytorch.org/get-started/locally/) для получения команды установки, специфичной для вашей системы
2. Установите PyTorch без CUDA поддержки: `pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu`

### Видео или изображения не отображаются

**Причина**: Проблемы с правами доступа или неправильные пути к файлам.

**Решение**:
1. Проверьте, что директории `uploads/` и `api_results/` существуют и имеют правильные права доступа
2. Проверьте логи сервера на наличие ошибок связанных с путями к файлам
3. Убедитесь, что ID анализа корректно передается между фронтендом и бэкендом

### Ошибка CUDA при анализе видео

**Причина**: Несовместимость GPU или отсутствие CUDA.

**Решение**:
1. Убедитесь, что у вас установлены драйверы NVIDIA и CUDA Toolkit
2. Если GPU недоступен, модель автоматически будет использовать CPU (с меньшей производительностью)
3. Убедитесь, что версия PyTorch и CUDA совместимы

## Оптимизация производительности

### Для более быстрого анализа:

1. Используйте более низкую частоту выборки кадров (например, 15-20)
2. Уменьшите разрешение видео перед загрузкой
3. Используйте GPU с поддержкой CUDA
4. Ограничьте количество анализируемых товаров в одном запросе

- Пакетная обработка кадров видео для эффективного использования GPU
